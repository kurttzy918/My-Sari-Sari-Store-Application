Install Kurt POS

Add this app to your home screen for a faster, offline-ready experience.

On desktop (Chrome / Edge):

  1. Look for the ⊕ Install icon at the right side of the address bar.
  2. Click it, then confirm Install.
  3. Or open the browser menu ⋮ → Install Kurt POS.

💡 Don't see the install icon? Make sure you're on https:// or localhost, and try refreshing once.

On iPhone / iPad (Safari):

  1. Tap the Share button at the bottom.
  2. Scroll and tap Add to Home Screen.
  3. Tap Add.

On Android (Chrome):

  1. Tap the ⋮ menu.
  2. Tap Install app or Add to Home screen.
