Install Kurt POS

Add this app to your home screen for a faster, offline-ready experience.

📱 On iPhone / iPad (Safari):

  1. Tap the Share button at the bottom of Safari.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add in the top-right corner.

💡 iOS doesn't allow websites to install themselves automatically — this is Apple's policy.

💻 On desktop (Chrome / Edge):

  1. Look for the ⊕ Install icon in the address bar.
  2. Click it → confirm Install.
  3. Or: menu ⋮ → Install Kurt POS.

💡 Make sure you're on https:// or localhost.

📱 On Android (Chrome / Edge):

  1. Tap the ⋮ menu (top-right).
  2. Tap Install app or Add to Home screen.
  3. Confirm by tapping Install.
